# LiveTranslate 文档

每次修改代码都要在这里留下对应的文档：说明为什么改、改了什么、怎么验证。

| 文档 | 内容 |
| --- | --- |

## 约定

- 文档按模块放子目录，例如 `asr/`（语音识别）、`translation/`（翻译）、`server/`（服务端）。
- 文件名用 `版本号-主题.md`，同一主题后续再改时在原文档末尾追加「变更记录」。
- 每篇文档至少包含：背景/问题、方案、涉及代码、验证方法、已知限制。
